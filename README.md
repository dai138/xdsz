# 线性代数智能刷题系统

98 道单选题（含逐选项解析）+ 7 道大题自评，错题记忆 + 知识点加权强化。
在线使用：https://dai138.github.io/xdsz/

## 功能

- 🧠 智能自适应练习：答错权重升高、优先重现，连带强化同知识点题目
- 📕 错题强化：只刷错题，直到清零
- 📖 顺序练习 / 按部分练习
- ✍️ 计算与证明题自评：先做后对照参考答案
- 📝 模拟考试：随机抽 20 题、限时 30 分钟倒计时，到时自动交卷；
  交卷后逐题复盘，错题自动进错题本
- 📊 统计：各章正确率、薄弱知识点、模拟考试记录、进度导出/导入

进度保存在浏览器 localStorage 中。
