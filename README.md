# 线性代数智能刷题系统

255 道选填题（239 单选 + 16 填空，均含逐题解析）+ 7 道大题自评，错题记忆 + 知识点加权强化。
在线使用：https://dai138.github.io/xdsz/

## 题库来源

| 来源 | 题量 | 说明 |
|---|---|---|
| 《矩阵与线性代数单选题题库》 | 98 | 原题库 |
| 《25级线性代数总复习》 | 157 | 老师在课上发的总复习资料：原填空 35 + 原单选 18 + 计算题转化 39 + 知识点转化 63（含 16 道填空题） |

复习资料的 25 道计算题和五大模块知识点，已全部转成选择题与填空题；
所有答案都独立重算验算过，可按“部分”筛选集中练习。

## 功能

- 🧠 智能自适应练习：答错权重升高、优先重现，连带强化同知识点题目
- 📕 错题强化：只刷错题，直到清零
- 📖 顺序练习 / 按部分练习（共五个部分，第五部分为相似矩阵与二次型）
- ✍️ 计算与证明题自评：先做后对照参考答案
- 📝 模拟考试：从单选题中随机抽 20 题、限时 30 分钟倒计时，到时自动交卷；
  交卷后逐题复盘，错题自动进错题本
- ✍️ 填空题：直接输入答案即可判分（忽略大小写与首尾空格）
- 📊 统计：各章正确率、薄弱知识点、模拟考试记录、进度导出/导入

进度保存在浏览器 localStorage 中。
